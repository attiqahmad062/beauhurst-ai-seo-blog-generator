# AI-Powered SEO Blog Generator

A reusable Nuxt.js application that transforms company CSV datasets into SEO-optimised, server-rendered industry articles using AI.

Built for the Beauhurst Web Developer technical assessment.

## Features

- **CSV upload:** Upload company datasets with automatic column detection, manual mapping and validation.
- **AI-generated content:** Generate industry-specific article introductions, headings and summaries using Google Gemini or local Ollama.
- **Accurate statistics:** Calculate fundraising totals, averages, medians and ranking metrics directly from CSV data.
- **SEO optimisation:** Dynamic titles, meta descriptions, canonical URLs, Open Graph metadata, structured data and sitemap support.
- **Server-side rendering:** Articles are rendered with Nuxt SSR, making their content accessible in the initial HTML.
- **Reusable workflow:** Create fintech, healthtech or other industry articles without modifying the source code.

## Tech Stack

Nuxt 4 · Vue 3 · TypeScript · Google Gemini / Ollama · Zod · Vitest

## Getting Started

**Requirements:** Node.js 22+, npm and a Gemini API key or a local Ollama installation.

1. Clone the repository and install dependencies:

```bash
git clone https://github.com/attiqahmad062/beauhurst-ai-seo-blog-generator.git
cd beauhurst-ai-seo-blog-generator
npm install
```

2. Configure environment variables:

```bash
cp .env.example .env
```

Edit `.env` and set:

```env
NUXT_AI_PROVIDER=gemini
NUXT_GEMINI_API_KEY=your_api_key
```

Alternatively, configure Ollama using the example environment settings.

3. Start the development server:

```bash
npm run dev
```

Open `http://localhost:3000`.

## How It Works

1. Upload a CSV through `/upload`.
2. Review detected columns and correct mappings if necessary.
3. Enter the industry and select the dataset currency.
4. The application validates the data and calculates statistics using TypeScript.
5. Gemini or Ollama generates editorial content based on the processed dataset.
6. The result is saved as a new article and displayed through a reusable Nuxt SSR page.

For the assessment, use `examples/OFFICIAL_fintech_companies_seed.csv` to generate the 100-company fintech ranking. A fictional healthtech dataset is also included to demonstrate reusability.

## Design Decisions and Limitations

Financial statistics are calculated deterministically rather than generated by AI. Model responses are validated before publication, and article text is rendered safely as text.

Generated articles use local JSON storage to keep the assessment implementation lightweight. This requires a persistent, writable filesystem and is not designed for serverless or multi-instance production deployment. A production system would benefit from database storage, authentication, rate limiting and editorial review of AI-generated content.
